# 拓展插件

方言**延伸内容**插件放置区。与 [`../技能插件`](../技能插件) 平级，二者由同一套发现机制扫描，
放进来的插件会自动被识别（无需修改配置）。

## 与「技能插件」的分工

| | 技能插件 (`../技能插件`) | 拓展插件（本目录） |
|---|---|---|
| 侧重 | 语言**能力**：听辨识别、词汇、发音、语法 | 文化**延伸**：俗语、歇后语、民谣、民俗 |
| 典型钩子 | `text.pre`（词汇/翻译改写）、`llm.providers` 等 | `text.pre`、`output.post`（口播素材/韵律） |
| 回答风格 | 问答 / 互译，可直接落到文本 | 素材展示、典故讲解、民俗背景 |

分界不是硬性的：如果某个插件**主要是为了教语言**，放技能插件；**主要是为了展示文化**，
放本目录。两边都能被加载，差别只在归类语义与后续检索便利性。

## 本目录当前内容：方言文化延伸插件族

13 个方言大区各一个 `dialect_<key>_extra`，与
[`../技能插件`](../技能插件) 下的同名技能插件**成对**存在
（`dialect_yue_skill` ↔ `dialect_yue_extra`）。

指令（写在合成文本的行首，中英文冒号都接受；**必须带方言简称**）：

| 指令 | 作用 |
|---|---|
| `<方言简称>俗语：<关键词>` | 俗语释义与出处 |
| `<方言简称>歇后语：<关键词>` | 歇后语前半句 → 补全后半句与释义 |
| `<方言简称>童谣：<关键词>` | 童谣词句与背景 |
| `<方言简称>民俗：<关键词>` | 岁时、饮食、信仰等民俗注解 |
| `俗语：<关键词>` 等（裸指令） | **跨方言检索**，一次列出所有命中的方言 |

检索是**子串匹配**，不必记得完整条目，给关键词即可。命中后指令会从朗读文本里被剥离。

### ⚠️ 为什么必须带方言简称

`text.pre` 是链式钩子，13 个拓展插件若都认裸的 `俗语：`，id 最小的那个会抢答一切查询、
对它不认识的词回「未收录」并剥掉指令，其余方言永远轮不到。
裸指令统一交给跑在最后的跨方言路由插件（`../技能插件/dialect_router`，`priority 20`）。
原因与实测证据见 [`../技能插件/README.md`](../技能插件/README.md) §2。

### 数据与「不虚构」的落实

`dialect_data.json` 的 `entries[].type ∈ {俗语, 歇后语, 童谣, 民俗}`；
每条必须带 `src` 与 `conf`，且 **`conf = "low"` 必须写 `note`** 说明待核实之处。
俗语、歇后语引《中国谚语集成》《中国歇后语大辞典》等真实汇编；
童谣属口传文学，`src` 统一写「民间口传（据通行唱法整理，非定本）」并附版本差异提示 ——
标明它不是定本，比假托一本出版物诚实。

采录确实不足的几个区（闽东／徽语／平话）**宁可少收并全标 low，也不凑数**，
`coverage_note` 会明说「某类目尚未采录，输入该指令只会得到未收录」。
另外：`未收录` ≠ 该方言没有这个说法，只表示本表没采到。

## 关于目录名

本目录名是**中文**（`拓展插件`），不是合法的 Python 标识符，因此**不能**直接 `import`。
插件通过清单文件发现并加载，与目录名无关；若在代码里需要定位本目录，请用路径而不是导入：

```python
import os
zone = os.path.join(os.path.dirname(__file__), "拓展插件")
```

## 新增插件的步骤

1. 在本目录下建一个子目录，目录名用插件 id（小写字母/数字/下划线），例如 `dialect_yue_extra`。
   方言文化插件建议用 `dialect_<key>_extra`，与 `../技能插件/dialect_<key>_skill` 成对。
2. 放入 `plugin.json`（清单）、`plugin.py`（入口）与 `dialect_data.json`（语料）。
   若走方言插件族，`plugin.py` 只需抄同族的薄壳（`from extra_factory import build`），
   指令前缀由 `lang_short` 自动生成，不必手写。
3. 清单里 `id` 必须全局唯一——**不要**与 `../技能插件` 下的插件重名，重名会被拒绝并告警。
4. `priority` 必须**大于**跨方言路由插件的 20（方言插件族用 60），否则会抢在路由之前
   把裸指令吃掉，跨方言检索就失效了。
5. 内容需注明**数据来源与置信度**，不得虚构民俗/俗语内容；
   `conf = "low"` 的条目必须写 `note` 说明待核实之处。
6. 不必手动登记到路由插件 —— 它启动时扫描本目录，自动并入跨方言检索。

最小 `plugin.json` 示例：

```json
{
  "id": "dialect_yue_proverb",
  "name": "粤语俗语与歇后语",
  "name_en": "Cantonese Proverbs & Xiehouyu",
  "version": "0.1.0",
  "api_version": "1.0",
  "entry": "plugin.py",
  "hooks": { "text.pre": "on_text_pre" },
  "enabled": true
}
```

完整契约（钩子清单、返回值语义、热重载、设置项）见 [`../README.md`](../README.md)。
