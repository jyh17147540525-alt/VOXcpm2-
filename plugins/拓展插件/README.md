# 拓展插件

方言**延伸内容**插件放置区。与 [`../技能插件`](../技能插件) 平级，二者由同一套发现机制扫描，
放进来的插件会自动被识别（无需修改配置）。

## 与「技能插件」的分工

| | 技能插件 (`../技能插件`) | 拓展插件（本目录） |
|---|---|---|
| 侧重 | 语言**能力**：听辨识别、词汇、发音、语法 | 文化**延伸**：俗语、歇后语、民谣、民俗 |
| 典型钩子 | `text.pre`（词汇/翻译改写）、`llm.providers` 等 | `text.pre`、`output.post`（口播素材/韵律） |
| 回答风格 | 问答 / 互译，可直接落到文本 | 素材展示、典故讲解、民俗背景 |

分界不是硬性的：如果某个插件**主要是为了教语言**，放技能插件；**主要是为了展示文化**，
放本目录。两边都能被加载，差别只在归类语义与后续检索便利性。

## 关于目录名

本目录名是**中文**（`拓展插件`），不是合法的 Python 标识符，因此**不能**直接 `import`。
插件通过清单文件发现并加载，与目录名无关；若在代码里需要定位本目录，请用路径而不是导入：

```python
import os
zone = os.path.join(os.path.dirname(__file__), "拓展插件")
```

## 新增插件的步骤

1. 在本目录下建一个子目录，目录名用插件 id（小写字母/数字/下划线），例如 `dialect_yue_proverb`。
2. 放入 `plugin.json`（清单）与 `plugin.py`（入口）。
3. 清单里 `id` 必须全局唯一——**不要**与 `../技能插件` 下的插件重名，重名会被拒绝并告警。
4. 内容需注明**数据来源与置信度**，不得虚构民俗/俗语内容。

最小 `plugin.json` 示例：

```json
{
  "id": "dialect_yue_proverb",
  "name": "粤语俗语与歇后语",
  "name_en": "Cantonese Proverbs & Xiehouyu",
  "version": "0.1.0",
  "api_version": "1.0",
  "entry": "plugin.py",
  "hooks": { "text.pre": "on_text_pre" },
  "enabled": true
}
```

完整契约（钩子清单、返回值语义、热重载、设置项）见 [`../README.md`](../README.md)。
